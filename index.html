Recent Projects

  •

    LA Smart Crime Insights

    EDA, Python (scikit-learn, pandas, numpy, matplotlib, seaborn), Tableau, ETL, Machine Learning

    This project analyzes Los Angeles crime data (2010-23) uncover temporal, spatial, and demographic patterns and to assess how the COVID-19 pandemic affected crime dynamics. I researched & collected LAPD crime datasets & cleaned them, merged with census data for the team to perform comprehensive insights into crime trends across the LA city & developed interactive statistical dashboard.

  • Brain Tumor MRI Dataset Analysis & Classification

    EDA, Jupyter Notebook, Python (scikit-learn, pandas, numpy, matplotlib, seaborn, PyTorch/TensorFlow for neural network models), Machine Learning

    This project used supervised, unsupervised and neural network models to solve brain tumor MRI images classification problem. I collected the datasets, preprocessed and analyzed them. Subsequently I built the classification models (MLP, CNN ResNET50) for tumor detection and segmentation.

  • Predictive Analytics for Chart-Topping Video Games Success

    EDA, Python, R, Linear Regression, Logistic Regression

    Utilize analytical methods to identify and understand the relationship between genres and platforms of video games and their market success based on historical sales data and user engagement (rating and metascore) metrics. I conducted EDA and built linear regression models with R to predict game sales.
